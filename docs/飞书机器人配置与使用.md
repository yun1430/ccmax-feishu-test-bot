# 飞书机器人配置与使用

## 结论

> 本仓库仅公开机器人适配器、配置文档和离线测试；完整测试需另行部署 CCMax 本地工作台，飞书应用需已具备签发 tenant_access_token 的资格。公开仓库不包含真实凭证、工作台或测试结果。

可以实现。本方案使用飞书企业自建应用、机器人能力和官方 SDK 长连接事件订阅，不需要公网 IP、域名或内网穿透。机器人只作为本机 CCMax 测试工作台的入口：在白名单群中 @机器人提交 URL、Key、Model，经发起用户二次确认后，串行调用本机工作台的两个既有接口，并生成 Markdown 测试报告发回原群。

> 机器人不会自行调用上游模型，也不会绕过现有付费授权。真实运行必须由用户明确确认；PASS 只表示本轮可执行断言通过，不代表模型官方身份、上游没有改写或没有隐藏提示。

## 一、飞书后台配置

1. 登录飞书开放平台，创建“企业自建应用”。
2. 在“添加应用能力”中启用“机器人”。
3. 在“事件与回调”中订阅 `im.message.receive_v1`，并选择长连接接收事件。
4. 在权限管理中至少开通：
   - 接收机器人被 @ 的群消息所需权限（按控制台当前权限名称开通；如继续使用单聊，也需单聊消息读取权限）；
   - `im:message:send_as_bot`：以机器人身份发送消息；
   - `im:resource` 或 `im:resource:upload`：上传并发送报告文件。
   实际可用权限名称以飞书后台当前展示为准；若后台按新版权限拆分，请按发送文本、发送文件所需权限分别授权。
5. 发布应用并将机器人可用范围限定为测试人员。
6. 获取 `App ID` 与 `App Secret`。Secret 只放在本机环境变量中，不提交到仓库、不粘贴到报告。

## 二、本机依赖与配置

```powershell
cd <本仓库所在目录>
python -m pip install -r requirements-feishu.txt
```

设置环境变量：

```powershell
$env:FEISHU_APP_ID = "cli_..."
$env:FEISHU_APP_SECRET = "..."
# 多个 open_id 用英文逗号分隔；不填时机器人拒绝所有用户
$env:FEISHU_ALLOWED_OPEN_IDS = "ou_..."
# 启用群聊：配置允许使用机器人的群 chat_id（多个用英文逗号分隔）
$env:FEISHU_ALLOWED_CHAT_IDS = "oc_..."
# 机器人自身 open_id，用于验证群消息确实 @ 到本机器人
$env:FEISHU_BOT_OPEN_ID = "ou_..."
```

可选变量：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `FEISHU_ALLOWED_CHAT_IDS` | 空（默认禁用群聊） | 允许机器人响应的群 `chat_id` 白名单，逗号分隔 |
| `FEISHU_BOT_OPEN_ID` | 空 | 群聊启用时必填；用于识别结构化 mentions 中的机器人身份 |
| `CCMAX_WEB_URL` | `http://127.0.0.1:8765` | 本地工作台地址，只允许回环地址 |
| `CCMAX_ANTHROPIC_AUTH` | `x-api-key` | 只能是 `x-api-key` 或 `bearer` |
| `CCMAX_CLASSIFIER_BETA` | 空 | 必须是具体的 `auto-mode-classifier-*` 值，禁止通配符 |
| `CCMAX_FEISHU_HTTP_TIMEOUT` | `120` | 每个请求的超时秒数，范围 10–120 |
| `CCMAX_ALLOW_PRIVATE_TARGETS` | 空 | 设为 `1` 才允许测试私网/回环目标；默认拒绝 |

查看配置但不连接飞书、不执行测试：

```powershell
python .\ccmax_feishu_bot.py --check
```

## 三、启动

先启动本地工作台：

```powershell
# 在另行部署的 CCMax 工作台目录启动：`python ccmax_web.py --port 8765`
```

另开一个终端启动机器人：

```powershell
python .\ccmax_feishu_bot.py
```

机器人启动后保持长连接，不需要开放本机端口给飞书。不要将 `ccmax_web.py` 暴露到公网。

## 四、使用流程

1. 将机器人加入受控测试群，并把该群的 `chat_id` 加入 `FEISHU_ALLOWED_CHAT_IDS`。仅群白名单内、同时属于用户白名单的成员可操作。
2. 在群里 @机器人，发送：

```text
@CCMax测试机器人 测试 https://your-gateway.example.com|YOUR_KEY|YOUR_MODEL
```

也可使用 `/test`：

```text
@CCMax测试机器人 /test https://your-gateway.example.com|YOUR_KEY|YOUR_MODEL
```

3. 机器人只做参数校验并在原群回复目标、模型、预算和确认令牌，此时尚未调用付费接口。
4. 核对目标后，在 10 分钟内 @机器人 回复：

```text
@CCMax测试机器人 确认 <令牌>
```

5. 机器人串行执行：
   - 截图对齐：最多 56 次请求；
   - Claude 透传：最多 10 次请求；
   - 总计最多 66 次请求上限。
6. 完成后机器人发送摘要和 Markdown 报告文件到原群；本地同时写入 `reports\feishu\` 下的 JSON 与 Markdown。

请求数上限不是金额上限。输入、输出、thinking、缓存和目标网关计费均可能产生额外费用；工具无法保证平台实际扣费。

## 五、安全与边界

- 群聊必须同时命中 `FEISHU_ALLOWED_CHAT_IDS` 群白名单、`FEISHU_ALLOWED_OPEN_IDS` 用户白名单，并且消息结构化 mentions 确认 @ 的是本机器人。
- 群内确认令牌绑定发起用户和原群；其他用户或其他群不能消费令牌。
- **群消息中的 Key、确认令牌、测试状态、摘要和报告对群成员可见，并可能保留在飞书消息历史中。只在成员可信、访问受控的测试群使用；不要用生产密钥或不允许群内披露的凭据。** 如不接受此风险，请不要在群内传 Key，改用私聊流程。
- 同一会话内同一 `message_id` 去重；去重状态仅在进程内，机器人重启后不会保留。
- URL 禁止用户名/密码、查询参数和片段；默认拒绝私网、回环和保留地址。
- 工作台地址仅允许本机回环地址；请求禁用系统代理和自动重定向。
- Key 只驻留内存，确认后从待处理表移除，任务结束删除任务对象；不写入日志或报告。
- 报告不包含 Key、原始提示词、原始响应或 SSE。
- 隐藏系统提示、中转出站请求、上游账号状态属于 `NOT_OBSERVABLE`，不能由本工具证明。
- 飞书事件回调只做内存入队，不等待网络；单 worker 串行执行付费任务，避免本地工作台并发冲突。

## 六、报告结论

| 结论 | 含义 |
|---|---|
| `OBSERVED_ANOMALIES` | 本轮出现 `FAIL` 或 `ERROR` |
| `INCONCLUSIVE` | 存在 `WARN`、`BLOCKED`、`NOT_OBSERVABLE`、`OBSERVED`、空结果等非 PASS 状态 |
| `NO_ANOMALY_IN_EXECUTED_CASES` | 本轮执行项全部为 PASS；仅限已执行用例，不代表模型身份认证 |
